# Decision: 슈퍼 관리자 권한 고정

- Date: 2026-11-02
- 사용자 요구: 역할별 권한 표에서 슈퍼 관리자를 제외하고 모든 권한을 갖도록 한다.
- 결정: 편집 표는 관리자·일반 사용자만 렌더한다. 슈퍼 관리자는 모든 지원 기능의 권한을 고정으로 갖는다는 안내를 표시한다.
- 권한 판정은 슈퍼 관리자의 저장된 체크값에 의존하지 않고 기존 `CRUD_CEILING`의 지원 작업 전체를 허용한다. 로그 삭제처럼 원래 없는 업무 작업을 신설하지 않는다.
- 기존에 낮춰진 슈퍼 관리자 권한은 mock 초기화에서 고정값으로 정상화한다. 저장 요청의 슈퍼 관리자 권한 변조는 서비스 검증에서 거절한다.
- 기존 3역할 저장 계약과 권한 revision 충돌 검사는 유지한다. 관리자·일반 사용자 상한, 부서 범위, 활성 계정·자기 삭제 방지 등 업무 검증은 유지한다.
- 현재 mock 서비스 범위의 변경이다. 실제 서버 인증/DB 연결을 새로 구현하거나 클라이언트 검증을 서버 보안으로 표현하지 않는다.
- 테스트는 기존 사용자 결정대로 로컬에만 보관한다. 브라우저 검증 제외 정책을 유지한다.

명확한 단일 변경 요청으로 추가 인터뷰 분기 없이 계획·구현한다.
