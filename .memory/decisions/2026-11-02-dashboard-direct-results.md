# 대시보드 필터와 결과의 거리 개선
- Date: 2026-11-02
- Status: confirmed
- 사용자 요청: 상단 필터를 눌렀는데 최하단 RFP 목록만 바뀌어 스크롤해야 하는 대시보드 UX 개선. 공통 컴포넌트 구조 고려.
- 기존 4개 분석 탭은 유지한다. RFP 현황에서는 목록/통계 보기로 나누고 기본은 목록이다. 목록은 RFP 상태 KPI → 탭/보기 전환 → 목록 순서로 즉시 노출한다.
- 활동 KPI5개는 사용량/작업·리소스/사용자 탭에서 표시한다. RFP 조회와 목록 사이에 삽입하지 않는다. 기존 모든 지표·차트·부서 집계는 유지한다.
- 상단 상태 카드는 언제나 해당 상태의 목록 1페이지로 이동한다. 같은 카드를 다시 눌러도 상태를 해제하지 않는다. 카드 수량은 전체 조회 기간 기준이므로 등록 구간 필터는 해제한다. 전체/해제 버튼으로 상태를 해제한다.
- 등록 차트/결과 분포 선택도 필터된 목록 보기로 전환한다. 등록 구간/상태 조건은 목록에 표시하고 개별 해제를 유지한다. 통계로 돌아와 선택 구간을 계속 확인할 수 있다.
- 기존 최하단 목록 이동 UI를 제거한다. 차트에서 목록으로 전환할 때는 가까운 목록 영역에 초점만 이동하고 preventScroll로 강제 스크롤을 막는다. 상단 상태 선택 시에는 클릭한 카드 초점을 유지한다.
- 기존 날짜 필터 위치·공통 토큰·권한·집계·10행 페이지·사용자 검색·비용 계산을 유지한다. 데이터/API 변경 없음.
- 이전 proposal-layout의 목록 최하단 배치 규칙은 이번 요청으로 대체한다. 브라우저 검증 제외·테스트 로컬 보관 유지. 로컬 커밋, push 없음.
