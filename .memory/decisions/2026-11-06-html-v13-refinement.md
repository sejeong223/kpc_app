## D03. 계획자 해석·기본값

- 첨부 첫 이미지는 돋보기−/100%/돋보기+ 줌 도구, 둘째는 분리선의 원형 좌우 조절 손잡이다. “AI 분석 항목 크기”는 글자 크기나 항목별 높이가 아니라 분석 패널의 가로 너비로 해석했다.
- 원문 줌 50~200%, 10% 단위, 100% 버튼은 초기화. 분석 폭 기본 380px/최소 280px/최대 680px와 원문 320px 여유를 둔다. 좁은 화면은 기존 1240px 적층 정책을 유지한다.
- RFP 도넛 112→176px, stroke 18→28, label 열 112px/gap 8px, 차트-범례 24px, 좁은 카드 440px에서 세로 배치한다.
- 폰트는 Spoqa Han Sans Neo + 기존 한국어 fallback. 관리자 폰트 family만 수정한다. 코드/ID monospace와 자산 미리보기 설정은 유지한다.
- 현재 개발 코멘트 UI는 작업 트리 기준이다. 진행 중인 미커밋 코드를 참고한 것이며 해당 코드의 완성/검증을 주장하지 않는다.
- v12 내용/표시/조작을 복원해도 현재 권한·고정 섹션·읽기 전용 상태는 보존한다. 원본 자산/PAGES/COMMENTS 전체 교체는 하지 않는다.

- 사용자 요청: 리뷰 화면의 “섹션 목록 / 사실검증 / 기본 배치” 버튼을 없애고, 섹션별 슬라이드를 모두 1장으로 두지 말고 여러 장으로 구성한다.

- 고정 시연 프로젝트의 데이터 없는 섹션 또는 1장인 섹션만 실제 페이지를 보완한다. 목표 2~4장과 순서 [2,3,4,3,2,4]는 계획자 기본값이다. 기존 페이지·id·인덱스를 유지하고 새 페이지마다 서로 다른 본문·구성을 둔다. 공통 pagesOf fallback과 사용자가 새로 만든 프로젝트는 바꾸지 않는다.
- 같은 PAGES를 사용하는 리뷰·목차·제작의 장수 일치는 이번 추가 요청에 필요한 범위다. 기존 다중 페이지나 COMMENTS/FACT의 장별 연결·권한·완성본 이력을 교체하지 않는다.
