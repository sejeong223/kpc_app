# 대시보드 사용자 정보 누락 보완
- Date: 2026-11-02
- Status: confirmed
- 사용자 요청: 직전 대조에서 확인된 미반영 항목(사용자별 이메일 표시·검색·아바타)을 추가한다.
- 기획 HTML의 사용자 식별 영역을 구현한다. 이름·부서·이메일·이름 기반 아바타를 표시하고 기존 이름/부서 검색에 이메일 검색을 더한다. 실제 프로필 사진 조회나 새 외부 요청은 추가하지 않는다.
- 현재 DashboardView의 사용자 집계에 email:string|null을 추가한다. 조회 범위 내 최신 활동 이력의 actorEmail을 우선하고, 이력이 없으면 삭제되지 않은 조회 가능 사용자 정보의 이메일을 쓴다. 이외에는 null로 두고 이메일 정보 없음을 표시한다.
- 부서·기간 범위 필터 이후의 이력만 사용한다. 다른 부서로 이동한 사용자나 삭제 사용자에 대해 현재 프로필 이메일을 임의로 가져오지 않는다. 기존 이력·토큰 합계는 유지한다.
- AdminUserIdentity 공통 컴포넌트를 만들어 활동 로그의 기존 식별 셀과 대시보드에 적용한다. Fluent Avatar를 재사용하고 Tailwind/공통 여백 토큰으로 배치한다.
- 검색은 공백 정리·대소문자 무시, 1페이지 초기화·입력 초점·10행 조회 유지. 기획 요소 이외 화면 구조는 유지한다.
- 브라우저 검증 제외·테스트 로컬 보관 정책 유지. 단일 로컬 커밋, push 없음.
