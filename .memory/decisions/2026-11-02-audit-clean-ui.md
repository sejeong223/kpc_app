# 활동 로그 UI 정리
- Date: 2026-11-02
- Status: confirmed
- 요청: 활동 로그 화면을 더 깔끔하게 개선하며 항상 컴포넌트 구조를 고려한다.
- 큰 전체/성공/실패 카드와 별도 조회 카드를 하나의 목록 카드 상단으로 통합한다. 건수는 결과 선택 칩, 기간은 compact 입력, 내보내기는 우측 액션으로 제공한다.
- 사용자/대상 검색과 액션/리소스 선택은 보조 필터 행에 모은다. 중복 결과 select는 건수 필터로 통합한다.
- 기본 표는 상세·시간·사용자·작업·대상/리소스·결과·토큰의 7열로 정리한다. 원래의 액션/세부작업, 리소스/대상을 각각 묶고 대상 ID는 상세에 둔다.
- 원래 데이터는 상세와 CSV에 모두 유지한다. 상세는 이벤트 정보/사용자·접속 정보로 나누고 실패 사유를 먼저 표시한다.
- 공통 DADAM 컨트롤/SegmentedControl/WorkspaceActionRow/AdminTable/AdminPager를 재사용한다. 업무 전용 요약 필터·결과 배지를 분리한다.
- 10행 기본 조회·정렬·CSV 전체 결과·권한 범위 유지. 검색 입력 직후 내보내기에도 최신 검색어를 적용하고 초기화는 날짜의 잘못된 초안도 해제한다.
- 브라우저 검증 제외/테스트 로컬 보관 정책 유지. 검증 후 로컬 커밋, push 없음.
