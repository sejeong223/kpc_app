# Decisions: 모든 Task에서 브라우저 검증 제외

- Date: 2026-10-30
- Status: Confirmed
- Scope: 이 워크스페이스의 현재 및 앞으로 작성·실행하는 모든 Task
- Source: 사용자 직접 지시 — “브라우저 검증은 앞으로 모든 Task에서 제외해줘.”

## D01. 지속 적용 규칙

앞으로 모든 Task의 Implementation/Acceptance Criteria/Validation/완료 판정에서 수동 브라우저 검증, Computer Use, 브라우저 E2E, 스크린샷/육안 비교, native IME/터치 확인, 브라우저 검증용 dev server 실행을 제외한다. 기존 청사진에 남아 있는 브라우저 검증 지시는 이 결정으로 대체한다. 사용자가 나중에 명시적으로 다시 요청한 경우에만 해당 범위를 수행한다.

이는 검증을 모두 없애라는 의미가 아니다. 변경에 맞는 단위 테스트·jsdom 통합 테스트·타입 검사·lint·build·정적 코드 검토는 유지한다. CSS 값을 복제하는 테스트나 새 자동화 도구를 대체 명목으로 추가하지 않는다.

## D02. 결과 기록

브라우저 검증을 미실시한 사실과 자동 검증의 범위를 구분한다. 브라우저 검증이 제외되었다는 이유로 Task를 in_progress 또는 blocked에 남기지 않는다. 통과하지 않은 자동 검증은 면제하지 않는다. 미실시한 항목에 “통과”를 기록하지 않는다.

새 Plan·Task와 `.memory/current.md`에 이 정책을 반영하고, 다른 활성 계획으로 전환할 때도 이어서 기록한다. 기존 결정의 브라우저 필수 검증 요구보다 이 사용자 지시가 우선한다.

## D03. 기존 제작 핀 코멘트 정리

T03·T04는 구현 커밋62b9e58/8a0f767 및 기존 보고서의 전체404개 테스트·typecheck·lint·build 통과 기록이 있다. 남아 있던 브라우저 요구만 제외하고 Task/phase/plan을 done으로 정리한다. 이번에는 앱 코드 수정·새 구현 커밋·자동 테스트 재실행을 하지 않는다. 기존 미실시 기록은 실행 이력으로 보존하며 새 정책 적용 일자를 덧붙인다.
