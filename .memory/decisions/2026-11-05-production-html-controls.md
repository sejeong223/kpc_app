# Decisions: 제작 화면 HTML 외 조작 요소 정리

- Date: 2026-11-05
- Status: Confirmed
- Source: 사용자 사진의 모두 선택·선택 해제·복사·삭제·이동할 소목차·선택 이동 및 HTML에 없는 다른 버튼 제거 요청.

1. 대상은 현재 제작 본문의 슬라이드 목록/편집·슬라이드/출처다. 기존 헤더·코멘트와 다른 메뉴를 변경하지 않는다.
2. 기준은 첨부 HTML의 실제 wsWrite → writeThumbs/multiPrompt/srcPanel 경로다. 호출되지 않는 옛 ctxPanel의 AI 빠른 요청 UI는 제작 화면 근거로 사용하지 않는다.
3. 목록의 상시 일괄 도구·체크박스·더보기와 복제·위/아래 이동·닫기 버튼 제거. HTML의 우클릭 복사/붙여넣기/삭제/추가, Ctrl/Meta·Shift 선택 및 Escape 해제를 유지한다. 도메인의 복사/삭제/이동 기능과 저장 자료를 삭제하지 않는다.
4. 중앙 문서 도구·파일 선택·Template 연결 설정·단일 AI 요청·추가/붙여넣기 상단 버튼·한 장씩 편집을 제거한다. 편집 입력/반영 아이콘, 소목차/작성 상태/고정 해제는 HTML에 있으므로 유지한다. 다중 요청은 textarea+반영 아이콘만 남긴다.
5. 출처는 원문 열기 별도 버튼 대신 클릭/키보드로 여는 카드로 만든다. 미리보기 전체 본문 토글 및 별도 재시도/선택 바로잡기 버튼도 제거하고 필요한 오류·초과 안내는 텍스트로 표시한다.
6. 저장 충돌/IME/dirty 보호와 기존 확인 대화상자, 권한/회차 검증은 유지한다. 없는 버튼을 다른 더보기/접힌 메뉴로 옮겨 숨기지 않는다.
7. tests/ 생성 금지 및 브라우저/dev server 검증 제외를 유지한다. 타입/lint/build와 필요한 stdin React/jsdom 상호작용 검증을 수행한다.
