# 대시보드 시각·정보 구조 전면 개선
- Date: 2026-11-03
- Status: confirmed
- 사용자 요청: 게시판처럼 느껴지는 현재 화면을 세련되고 정돈된 대시보드로 전면 개선. 구체적 배치·표현은 구현 판단이며 사용자의 개별 선택으로 기록하지 않는다.
- 기본 진입을 개요로 변경한다. 핵심 지표 4개(등록 RFP·진행 중·수주율·AI Token), 등록 추이/현재 상태 구성, 부서별 등록 상위 4개/활동 요약으로 시각적 우선순위를 만든다.
- 5개 탭: 개요 / RFP 현황 / 사용량 트렌드 / 작업·리소스 / 사용자별 현황. 기간·활동 로그 링크는 같은 도구 행에 유지. 메뉴 제목 중복·예시 데이터/화면 안내는 추가하지 않는다.
- RFP 탭은 작은 상태 필터 6개와 목록/추이·분포/부서별 보기를 제공한다. 대형 KPI 반복·중첩 표를 줄인다. 개요 카드·상태·차트 선택은 필터된 목록을 상단에 즉시 표시하고 1페이지로 초기화한다. 부서 전체 보기 역시 바로 부서 표로 연결한다.
- 기존 기획의 상태 6개, 등록 차트, 분포·범례·수주율·수주 금액·Drop 비율, 부서별 표, RFP 목록, 활동 5지표, 3개 추이, 작업 분류, 사용자 검색/이메일/아바타/10개 페이지를 유지한다.
- 공통 AdminMetric의 insight 표현, DashboardCard, 등록 차트 패널을 재사용하고 상태 구성/부서 요약을 분리한다. 공통 Button 및 기존 차트/여백·색상 토큰 활용. 중립 표면·파란 강조색, 큰 숫자, 단순한 축·범례, 영역 선 차트로 표현한다. 임의 성장률·실시간 표시·전환 퍼널·AI 해석을 만들지 않는다.
- 개요·활동은 기간 전체 summary 쿼리를 사용해 상세 필터가 전체 집계를 바꾸지 않게 한다. 권한/기간/이메일 이력/비용 원장 변경 없음. 활동의 실제 90일 보관 기간을 명시한다.
- 참고: https://learn.microsoft.com/en-us/power-bi/create-reports/service-dashboards-design-tips (핵심 정보 우선·상세 조회 분리), https://www.ibm.com/design/language/data-visualization/design/basics/ (간결한 축·의미 있는 색·요약 후 상세). 최신 유행을 수치로 단정하지 않는다.
- 최신 AGENTS.md에 따라 tests/ 생성·복원 금지, 기존 폴더 삭제도 하지 않음. typecheck/lint/build/정적 검토로 검증. 브라우저·E2E·dev server 제외 정책 유지. 단일 로컬 커밋, push 없음.
