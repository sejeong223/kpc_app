# Decision: 대시보드 헤더 간소화
- 요청: 대시보드 날짜 필터의 공간을 줄이고 예시 데이터·화면 안내 문구를 제거한다.
- 날짜 공통 컴포넌트에 compact 옵션을 추가한다. 대시보드는 기존 compact 요청을 전달해 높이 32px, 날짜 너비 132px, 기간 너비 112px, 간격 4px로 표시하고 중복 기간 라벨은 보조기술용 이름으로 유지한다.
- 공통 헤더의 데이터 안내·화면 안내 버튼과 펼침 영역을 제거하고 불필요해진 props·호출부도 정리한다. 제목·메뉴·업무 액션·본문의 의미 있는 기간 제한 안내는 유지한다.
- disabled option이 포함된 활성 select를 비활성처럼 칠하던 공통 CSS selector도 실제 입력 요소에 한정한다.
- 자동검증 및 단일 로컬 커밋. 브라우저 검증 제외·테스트 로컬 보관 정책 유지. push 없음.
