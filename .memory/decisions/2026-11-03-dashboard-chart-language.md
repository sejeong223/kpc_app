# 대시보드 그래프 색상·표현 개선
- Date: 2026-11-03
- Status: confirmed
- 사용자 요청: 개요·작업리소스·사용량 트렌드·사용자별 현황의 파란색 편중과 단조로운 막대 표현 개선.
- 데이터 의미에 따라 색과 형태를 구분한다. 등록은 파랑, 활동은 청록, Token은 보라, 활성 사용자는 황토색. RFP 성공/실패/대기 등의 기존 상태 색상은 보존한다.
- 개요: 등록 막대의 구간 선택 유지, RFP 상태는 도넛/클릭 가능한 범례, 부서 순위는 점·선 비교.
- 사용량: 추천(활동 영역·Token 막대·사용자 선)을 기본으로 추가하고 기존 전체 막대/선 선택을 유지한다.
- 작업·리소스: 액션 구성 도넛, 리소스 구성 누적 띠, 업무 상세 점·선 비교. 분류가 많으면 구성 그래프는 상위5개+기타로 요약하고 전체 상세/실패 수/10개 페이지도 제공한다. 색은 순위/페이지가 아니라 분류 ID 기준이다.
- 사용자: 총 활동 수와 함께 성공/실패 구성의 작은 링·성공률을 표시한다. 활동 0건은 회색 링/—. 검색·이메일·아바타·전체 수치·10행 페이지 유지.
- 팔레트는 theme CSS + config, 구성 차트·링·점 비교는 공통 컴포넌트로 관리한다. 숫자/범례/정확한 수치/빈 상태와 키보드 선택을 보존한다. 서비스·스키마·데이터를 변경하거나 임의 성장률/과거 추이를 생성하지 않는다.
- tests/ 생성·복원 금지, 브라우저 검증 제외 정책 유지. typecheck/lint/build/정적 검토 후 로컬 단일 커밋, push 없음.
