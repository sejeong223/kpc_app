## 데이터 보존 및 시연 경계

- 새 프로젝트 ID `production-html-mfg-demo`, 별도 fixture revision `mfg-v13-1`. 기존 `production-html-demo` 및 일반 프로젝트는 초기화/마이그레이션 덮어쓰기하지 않는다.
- 신규 예시를 기본 HTML 예시로 노출하고 기존 것은 `이전 HTML 예시 · 행정업무`로 구분한다. 명시된 기존 URL과 저장본 접근은 유지한다.
- 로그인 actor ID를 새 예시의 정소담 담당 ID로 사용하되 로그인 계정 이름/전역 role은 바꾸지 않는다. 예시 팀의 표시 이름만 정소담으로 둔다.
- 헤더 버튼 시연용으로 새 예시에서만 actor의 complete/rework/setup/assign 권한을 초기 grant에 부여한다. 원본 mfg의 일반 작성자에게 없는 완성/재작업 버튼을 확인할 수 있게 하는 의도적 보강이다. 실제 프로젝트 권한 확대는 없다.
- 설정의 `grant`는 UI 시연 키이며 영속 `ProjectPermission`에 추가하지 않는다. 설정에서 체크해도 실제 capability를 바꾸지 않는다.
- 출처 원문이 제공되지 않았으므로 HTML처럼 로컬 예시 본문 모달을 제공한다. 실제 파일 다운로드/업로드 또는 외부 RFP 연동을 가정하지 않는다. 기존 실제 원문 연결은 유지한다.
- 일반 프로젝트 데이터/권한/백엔드 동작은 유지하며 공통 헤더 및 제작 성공 문구 제거만 공통 적용한다.
