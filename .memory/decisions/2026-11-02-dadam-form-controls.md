# Decision: DADAM 공통 입력 컴포넌트
- 요청: 첨부 세 번째 DADAM 스크린샷의 룩앤필로 체크박스·대시보드 날짜 필터 등 입력 UI를 통일하고 컴포넌트화한다.
- 기존 구조: 관리 화면은 Fluent UI 직접 import, 날짜 필터는 24px small 컨트롤, 전역 빨간 테마와 일부 DADAM 테마가 혼재한다. 페이지 여백 토큰은 이미 공통화되어 있다.
- 기준: 입력 높이 38px, 목록 내부 compact 32px, 모서리 8px, 밝은 전체 테두리, 파란 선택·포커스, 비활성·오류 구분. 기존 페이지 간격 토큰은 재사용한다.
- 공통 토큰과 Fluent UI 기반 Button/Input/Select/Textarea/Checkbox 래퍼를 만든다. 네이티브 입력·label·ref·mixed·키보드 동작과 기존 API를 유지하며 관리자 메뉴에 일괄 적용한다. 직접 DOM 체크박스를 새로 구현하지 않는다.
- 날짜 범위 입력은 동일한 날짜 2개+기간 선택 컴포넌트로 통일하고, 좁은 화면 줄바꿈과 오류 메시지 연결을 지원한다. 기존 기간 검증·프리셋 의미는 유지한다.
- 공개 범위는 부서/그룹/사용자의 정렬된 선택 영역과 선택 수로 정돈한다. 기존 권한·저장 동작은 유지한다.
- 기존 전체 DADAM 테마를 전역 공급자에도 적용하고 KPC brand 토큰을 같은 파란 계열에 연결한다. 오류/삭제 위험 색상은 별도 의미 토큰으로 유지한다.
- 자동검증만 수행한다. 지속 지시에 따라 브라우저·E2E·스크린샷 비교·개발 서버는 제외한다. 테스트는 로컬만 보관하고 단일 로컬 커밋으로 완료하며 push하지 않는다.
