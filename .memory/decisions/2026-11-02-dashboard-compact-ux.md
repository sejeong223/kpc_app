# Decision: 대시보드 스크롤과 정보 구조 개선

- 사용자 요청: 대시보드의 과도한 스크롤을 줄이고 깔끔하고 편리한 UX로 수정한다.
- 기존 사용자 결정의 4개 탭(RFP/사용량/작업·리소스/사용자), 공통 기간, 전사·부서 권한 범위와 집계 의미를 유지한다.
- 구현 판단: 탭을 상단에 배치하고 해당 탭에 필요한 지표만 표시한다. 기간 필터는 제목 카드의 반복 높이를 줄인 공통 조회 영역으로 구성한다.
- RFP는 요약/목록/부서별 현황을 전환한다. 기본 요약에는 6개 지표와 나란한 추이·결과 분포를 표시한다. 기존 선택 구간 통계4개도 compact 요약으로 보존한다. 상태/차트 선택은 필터된 목록으로 연결한다.
- 사용량은 활동/토큰/활성 사용자 중 한 지표를 선택하고 막대/선 전환을 유지한다. 정확한 수치는 기존 펼침 데이터 표로 확인할 수 있다.
- 작업·리소스는 집계 기준을 선택하고 10개씩 표시한다. 페이지 간 막대 척도는 전체 선택 집계의 최대값을 사용한다.
- 사용자·부서 표는 공통10개 페이지를 사용한다. 검색/기간 변경 시 페이지를 초기화하며 현재 페이지·집계 기준·차트 종류는 상위 화면 상태로 보존한다.
- 사용자 검색 입력은 조회 중에도 유지하여 포커스와 입력이 끊기지 않도록 한다. 로딩·실패·권한 상태와 최근90일 집계 안내를 유지한다.
- 공통 카드/간격/탭/페이지/차트 컴포넌트를 재사용한다. 새 라이브러리, 고정 높이로 콘텐츠 숨기기, 본문 안의 추가 세로 스크롤은 도입하지 않는다.
- 실제 브라우저 검증은 지속 제외 정책을 유지한다. 테스트는 로컬에만 보관하며 단위/jsdom/typecheck/lint/build로 검증한다.
