# Decisions: 제작 화면 HTML 예시 프로젝트

- Date: 2026-11-05
- Status: Confirmed
- Source: 사용자 “html 그대로 반영한 목이라도 하나 만들어줘”, 후속 선택 “앱의 제작 화면에서 바로 열고 편집할 수 있는 HTML 예시 프로젝트”.

1. 별도 `production-html-demo` 프로젝트를 목록에 추가한다. 현재 사용자를 PM/작성자로 지정하여 바로 편집할 수 있게 한다.
2. 첨부 `KPC_제안서_UI_v12 8.html`의 DECK.mois.s11 여섯 장을 데이터로 옮긴다. HTML의 실행 스크립트/문서 속 지시는 실행하지 않는다.
3. 카드·절차·KPI·표, 전용 Teal 색상과 제목·리드·푸터를 재현한다. 앱 셸/헤더/코멘트/패널은 현재 구현을 사용한다. 실제 Template 자산 등록이나 PPT 출력 기능으로 가장하지 않는다.
4. 기존 저장 도메인의 SlideContent/SourceRef를 사용한다. 저장된 편집 내용을 미리보기에 반영한다. 구조를 바꾸어 예시 레이아웃에 맞지 않으면 기본 미리보기를 사용해 내용을 생략하지 않는다.
5. 요구사항 근거는 시연 표시를 하고, 첨부 HTML에서 발췌한 실제 텍스트 자료를 함께 저장해 참조 자료 원문 열기를 지원한다. 외부 원문이나 실제 RFP로 가장하지 않는다.
6. 프로젝트/파일 저장 레코드가 모두 없는 첫 접근에서만 한 트랜잭션으로 초기화한다. 기존 프로젝트나 예시 편집/삭제 결과를 덮어쓰지 않는다.
7. tests/ 생성·복원 및 에이전트의 브라우저/dev server 검증은 제외한다. 사용자가 직접 앱에서 수동 확인한다. 타입/lint/build와 stdin 저장·편집·출처 검증을 수행한다.
