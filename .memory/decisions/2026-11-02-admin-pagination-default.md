# Decision: 목록 기본 조회 개수 10개

- 사용자 요구: 사용자 설정, 활동 로그 등 한 페이지당 기본 10개씩 조회.
- 기존 페이지 구분이 있는 사용자·그룹·활동 로그·Skill·Template·적용 결과 목록의 기본값을 10으로 통일한다. 이미 10개인 대시보드 RFP 목록도 같은 설정을 참조한다.
- 현재 20/50개 선택 기능은 유지하고 활동 로그에는 10개 선택을 추가한다. 필터 초기화는 10개로 복귀한다.
- `config/pagination.ts`를 기본값·선택값의 공통 원본으로 사용한다. 기존 Zod의 허용값10/20/50과 권한·필터·정렬·내보내기 계약은 유지한다.
- 편집 모달의 최신 항목 조회20/50개는 목록 페이지 크기와 다른 용도이므로 변경하지 않는다. 페이지 구분이 없는 요약 표에 새 페이지 기능을 추가하지 않는다.
- 명확한 기본값 변경 요청으로 추가 질문 없이 계획 후 구현한다. 테스트는 로컬 보관, 브라우저 검증은 기존 정책대로 제외한다.
