# 사용량 트렌드 그래프 교체
- Date: 2026-11-03
- Status: confirmed
- 사용자 요청: 첨부한 사용량 트렌드 화면의 그래프를 다른 형태로 개선.
- 일별 0건/활동 집중일의 반복을 그대로 연결해 생기는 톱니 형태를 개선한다. 원본 값을 보간하거나 임의 추세를 만들지 않는다.
- 추천 화면에서 활동 수·활성 사용자는 월요일 시작의 주차×요일 히트맵을 사용한다. 칸마다 값, 날짜 선택/호버/키보드 이동, 강도 범례, 원본 일별 표를 제공한다. 활동이 없는 날(0)과 집계값이 없는 칸을 구분한다.
- Token은 월~일 주별 합계 막대로 표시한다. 처음/마지막 주는 조회 범위 내 날짜만 집계하며 주별 기간과 원본 일별 데이터를 제공한다. 활성 사용자의 일별 고유 인원을 합산하지 않는다.
- 기존 일별 막대/선 전환은 유지하되 기본 추천 화면은 새 패턴 보기로 교체한다. 기간/집계 범위/필터와 다른 대시보드 탭은 유지한다.
- 공통 날짜 차트 계산·히트맵·데이터 표를 재사용 컴포넌트로 분리한다. 기존 날짜 검증 스키마·차트 팔레트·버튼을 재사용한다.
