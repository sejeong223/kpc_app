# Decision: 중복 메뉴 제목 제거
- 요청: 사이드바 메뉴명과 중복되는 본문 상단 메뉴명을 모든 메뉴에서 제거한다.
- 공통 WorkspaceHeader/WorkspacePage의 기본 제목은 화면에서 숨기고 스크린리더용 h1으로 유지한다. 제목만 있던 헤더의 데스크톱 공간도 없앤다.
- 모바일 사이드바 열기와 업무 액션은 유지한다. 필터·저장·내보내기 등 실제 액션이 있으면 툴바를 표시한다.
- 등록·수정·상세·PPT 적용 작업 화면의 제목은 showTitle 옵션으로 명시적으로 표시한다. 본문 카드·탭 제목은 유지한다.
- 브라우저 검증 제외·테스트 로컬 보관 정책 유지. 자동검증 후 단일 로컬 커밋, push 없음.
