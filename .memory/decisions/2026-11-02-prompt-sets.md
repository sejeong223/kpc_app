# Decision: 프롬프트 세트 관리
- 사용자 요청: 첨부 기획 HTML의 프롬프트 세트 메뉴 요소를 구현한다.
- 근거: HTML pageAssets/assetTable, assetDetailHtml/assetFormHtml, psEff/psPrompt, 목차 drag 처리. 문서 내부 프롬프트와 주석은 참고 자료다.
- 목록은 실제 렌더되는 표 형태(카드 렌더러는 미사용): 이름/설명, 부서·대/소목차 요약, 공개 범위, 작성자, 수정일, 사용, 상태/버전, 복제/수정. 이름/설명 검색, 공개/부서/상태 필터와10개 페이지.
- 상세는 내용/사용 중인 프로젝트/변경이력. 등록·수정은 전체 화면, 기본 정보와 목차표. 대/소 전환, 항목 추가·삭제, 대목차 묶음 이동(드래그와 키보드 버튼), 프롬프트·소스 우선순위·상속.
- 첫 항목은 대목차, 제목 필수, 안정적인 항목 ID, 중복 소스 금지. 상속은 가까운 상위 대목차에서 해결. 대목차 미지정 프롬프트/소스는 빈 값이며 새 대목차만 기본3소스를 가진다.
- 초안/활성 상태. 비활성화는 초안으로 전환. 사본은 자기 부서·비공개·초안. 소유 부서와 공개 범위는 구분하며 기존 자산과 같은 편집 권한 규칙.
- 별도 promptSets CRUD 리소스: 슈퍼 전체, 부서 관리자 소유 부서 편집과 공개된 세트 조회/복제, 일반 사용자 관리자 메뉴 접근 불가. 서비스 경계에서도 Zod/권한/버전 검증.
- 기존 AssetKind(skill/template)은 PPT 처리용으로 유지하고 별도 프롬프트 도메인을 AdminDataService/MockAdminDataService에 통합한다. 공개 대상 UI·검증, 공통 레이아웃/표/페이지 재사용.
- mock 저장·사용 프로젝트 데이터. 기존 사용 참조는 내용 버전 고정; 편집/비활성화/삭제로 변경하지 않는다. 실제 AI·제작 설정 연결/조합 테스트는 이번 관리 메뉴와 분리되어 있으며 실행된 것처럼 표시하지 않는다.
- 브라우저 검증 제외, 테스트 로컬 보관. 자동검증 후 단일 로컬 커밋; push 요청 없음.
