# 제작 프롬프트 줄글 수정

- 사용자 후속 요청: 제목과 항목을 나열한 초기값 대신, 전체 내용이 자연스러운 문장으로 이어지는 통프롬프트를 표시한다.
- 원인: `readSlidePrompt`가 원문 없는 슬라이드의 title/lead/blocks를 줄바꿈으로 이어 붙여 결과물의 구획을 그대로 노출했다.
- 제조업 46장과 기존 HTML 예시 6장에 슬라이드 내용에 맞는 한 문단의 요청문을 추가했다. 제목/본문/표를 별도로 지정하는 문법이나 입력 구역은 없다.
- 기존 기본 슬라이드와 내용이 일치할 때 조회 시 적용하므로 이전에 생성된 예시에도 초기화 없이 반영된다. 수정된 슬라이드는 자신의 내용에서 줄글을 구성한다. 사용자가 이미 저장한 editorPrompt는 원문 그대로 읽는다.
- 작성 중 입력창과 완료 카드가 같은 readSlidePrompt를 사용한다. 데이터/PPT/댓글/완료 상태는 변경하지 않고 실제 AI 호출도 추가하지 않았다.
- 입력창 placeholder도 자연스러운 줄글 작성 안내로 바꿨다. 공용 버튼 리팩토링 없음. DadamControls.tsx SHA256은 이전 완료 값과 동일하다.

## 검증

- `npm.cmd run typecheck` 통과.
- 변경 3개 코드 파일 ESLint 통과.
- Node stdin 검증: 제조업 46장 + HTML 6장 전체 예시가 줄바꿈/탭 없는 요청문이고, 동일 슬라이드의 writing/done에서 같은 줄글을 반환한다.
- 지적한 mfg-s31-1의 정확한 줄글, 사용자 저장 원문·빈 원문 보존, 수정 슬라이드의 자기 내용 사용, 일반 목록/표/이미지 fallback을 확인했다.
- 전체 예시의 로컬 배치·저장 스키마·기존 블록 ID 보존과 조회 함수의 입력 불변성을 확인했다.
- 브라우저 시각 검증·테스트 폴더·임시 검증 파일 생성 없음.
