## 빠진 기능으로 오인하면 안 되는 변경/후속

1. **새 제작 편집기 노출 철회**: [복원 기록](./2026-11-03-production-collaboration-restoration.md)과 [11/04 결정](../decisions/2026-11-04-workspace-shared-header-files.md)이 우선한다. 3패널 슬라이드 편집·AI diff 등의 소스가 남아 있어도 현재 `/workspace/write`에서 제공된다고 말할 수 없다. 사용자 요청에 따라 동료 화면을 유지한 결과다.
2. **AI 분석·리뷰 본문 / 검토 목록·완료한 제안**: 공통 헤더/진입 경계 또는 메뉴만 있는 부분이다. 원본 HTML의 전체 업무 흐름이 구현됐다는 뜻이 아니다. 각각 확정된 범위 밖이다.
3. **실제 연결**: Cosmos DB/Blob·서버 인가·여러 PC 공유·실제 AI/RAG/OCR/웹 검색·알림 발송·RFP 원본의 자료함 연결은 후속이다. 이번에 Azure 자원을 만들지 않았다.
4. **관리자 자산 수명**: 관리자 목록은 메모리, 프로젝트 사본과 파일은 로컬 IDB다. 새로고침으로 원본 확인이 불가하면 재선택하는 사용자 선택을 유지했다. 이를 완전한 장기 자산 관리라고 표현할 수 없다.
5. **Template 브랜드 편집**: 전역 색상 변경/새 로고 삽입은 D17에서 후속으로 결정했다. 추출 정보 조회와 실제 지원 변환을 구분한다.
6. **프로젝트 설정**: 기본정보 수정·알림 설정 저장/발송·프로젝트 활동 로그는 현재 미연결 안내다. 관리자 활동 로그와 다른 기능이다.
7. **이전 문서 상태**: 10/29 관리자 T09의 미완료 기록, 10/30 개선 계획의 상단 진행표와 하단 7/7 완료 기록, 11/03 계획 초기 포인터 문구가 남아 있다. 역사적 상태와 현재 상태가 혼재한 기록 문제다. 현재 포인터는 11/04 계획 10/10 완료이며, 브라우저 제외 정책으로 과거 미실시 결과를 새 통과 결과로 덮어쓰지 않았다.

위 범위를 제외하고 이번에 대조한 확정 항목에서 추가 기능 누락은 발견하지 못했다. 모든 코드 경로·고객 파일·장치에 대해 결함이 없다는 보장은 아니다.

## 남은 운영 의존성 문제

`npm audit --omit=dev --json` 결과 **11개 취약 패키지 집계(Critical 3 / High 6 / Moderate 2)**, exit 1. [원본 audit](./2026-11-04-full-audit-dependencies.json)에 영향 버전·advisory URL·수정 가능 여부를 보존했다.

- Critical로 집계된 패키지: `next`, `next-auth`, 간접 `fast-xml-parser`.
- 그 외 `@azure/msal-node`, `node-forge`, `zod`, `sharp` 등도 포함한다.
- 이는 현재 설치 의존성에 대한 registry advisory 집계이며, 11개가 모두 이 앱에서 실제 공격 가능하다는 실증은 아니다. 코드 실행 취약성을 직접 재현하거나 공격성 입력을 실제 서비스에 보내지 않았다.
- [기존 후속 B01](./2026-10-30-admin-review-followups.md)에서 별도 작업으로 분리한 의존성 갱신은 아직 끝나지 않았다. `npm audit fix --force`, 패키지 설치/버전/lock 변경을 하지 않았다.
- 다음 의존성 작업에서는 사용 경로·영향 조건 확인 후 호환 가능한 수정 조합을 정하고 인증·빌드·서버 경계를 재검증해야 한다.
