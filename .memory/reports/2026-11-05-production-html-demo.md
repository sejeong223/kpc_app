직접 경로는 `/workspace/write?project=production-html-demo`이다. 새 코드가 반영된 앱에서 처음 열면 자료와 슬라이드가 생성된다.

## 구현 결과

- 첨부 HTML의 DECK.mois.s11 여섯 장: 사업 추진 배경, 사업 목적, 기대 효과, RFP 핵심 요구 분석, 사업 범위, 과업 구성.
- 원문 문구와 카드·절차·KPI·표, MOIS 전용 Teal(#0f5e63) 및 16:9 슬라이드 구성을 재현했다. 앱의 기존 헤더/코멘트/패널/편집기를 사용한다.
- 현재 사용자에게 PM/작성 권한을 부여한다. 기존 저장·편집 경로로 제목/리드/본문을 수정하고 저장할 수 있다. 구조가 예시 레이아웃과 달라지면 기본 미리보기로 전체 내용을 표시한다. 예시 레이아웃 본문 초과 시 전체 내용을 펼칠 수 있다.
- 출처 패널에 시연 근거와 HTML 발췌 텍스트 자료를 연결했다. 참조 자료의 원문 열기/다운로드는 저장된 실제 UTF-8 txt Blob을 사용한다. 실제 RFP로 가장하지 않는다.
- files/workspaces가 모두 없는 별도 예시 ID에서만 초기화한다. 파일 메타데이터·슬라이드·원문 Blob을 한 IndexedDB 트랜잭션으로 저장한다. 재접속/다중 조회 시 편집값을 덮어쓰거나 삭제된 슬라이드를 다시 채우지 않는다.
- 기존 프로젝트/자료/코멘트/DB를 초기화하지 않았다. Template 자산이나 영속 스키마를 추가하지 않았다.

## 수동 확인 포인트 및 제한

사용자는 프로젝트 선택 후 여섯 장 이동, 좌우 접기/펼치기, 편집 → 슬라이드 반영 → 새로고침, 출처 → 참조 자료 원문 열기를 확인할 수 있다.

이 프로젝트는 HTML 예시를 앱 안에서 보는 목이며 실제 PPT Template은 아니다. PPT 출력에는 별도 Template 연결이 필요하다. 새 블록 추가/복제 등으로 예시 전용 구조·ID에서 벗어난 슬라이드는 기본 미리보기를 사용한다. 실제 브라우저에서의 시각적 일치도는 검증하지 않았다.
