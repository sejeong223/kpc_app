복제는 독립된 새 자산

새 ID · 내용 v1 · 자기 부서 소유 · 비활성 · 비공개로 생성합니다. 원본에 대한 편집 권한을 얻는 기능이 아닙니다.

현재 권한은 매번 다시 검사

그룹 탈퇴/삭제, 부서 이동, 계정 잠금, read 해제, 공개 범위 축소는 기존 작업의 미리보기·적용·다운로드에도 반영됩니다.

실제 인증은 기존 서버의 User/Admin 가드를 유지합니다. 슈퍼 관리자/부서 관리자/일반 사용자 및 CRUD 세부 규칙은 이번 mock의 업무 정책 검증입니다. 향후 서버 연동에서도 동일 검증이 필요합니다.

같은 파일과 교체 파일의 상태 경계

같은 원본 파일의 최신 버전을 적용하면 선택 슬라이드·배치·이미지·공유 편집은 유지하고 등록 매핑만 갱신합니다. 새 파일 교체가 성공하면 선택과 문서별 편집 위치를 새 기본값으로 초기화합니다. 실패하면 이전 결과를 보존합니다.

취소와 폼 폐기를 구분

AdminTabs · Tailwind 레이아웃
